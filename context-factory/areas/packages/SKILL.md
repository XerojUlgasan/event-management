# Packages

For every UI change, read the [frontend entry](../frontend/SKILL.md), its [project structure](../frontend/references/project-structure.md), and the [reuse workflow](references/reuse.md). Inspect relevant exports, implementations, stories, styles, tokens, contracts, and consumers; complete the workflow's audit even when no package file changes.

- Package boundaries or public exports: [ownership and exports](references/ownership-and-exports.md).
- Component selection, APIs, or stories: [Clemora UI usage](../frontend/references/clemora-ui.md) and [components and Storybook](references/components-and-storybook.md).
- Shared styles, theme, or package verification: [theme and verification](references/theme-and-verification.md).
- shadcn setup, registry components, presets, or migration: [Clemora integration](references/shadcn.md), then the installed [shadcn skill](../../../.agents/skills/shadcn/SKILL.md).
- Shared validation constants or API caps: [contracts](../contracts/SKILL.md).
