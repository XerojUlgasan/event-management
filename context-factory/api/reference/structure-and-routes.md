# API structure and routes

- `apps/api/src/index.ts` starts the Node server. `src/app.ts` builds the `OpenAPIHono<HonoEnv>` app, configures CORS and request guards, injects `db`, mounts controller groups at `/v1`, and serves `/openapi.json`.
- `src/controllers/<domain>/index.ts` registers routes and middleware. Each operation has a kebab-case verb–entity file exporting `<operation>Route` and `<operation>RouteHandler`; the route defines method, path, request and response schemas, while the handler maps validated input and service outcomes to HTTP responses. The active domains are `auth/`, `packages/`, `services/`, `messages/`, `booking-requests/`, `venues/`, `users/`, and `health/`.
- `src/services/<domain>/<verb>-<entity>.ts` owns business rules and coordinates transactions and data calls. Exports use the `<operation>Service` suffix. A service is optional for an operation with no business work, such as health.
- `src/data/<domain>/<verb>-<entity>.ts` owns focused Kysely queries and accepts a database client or transaction. Exports use the `<operation>Data` suffix. `src/db/` remains the shared connection, generated types, and database setup area.
- `src/utils/` holds reusable primitives; auth-specific and package-specific helpers can use `utils/auth/` and `utils/packages/`. `src/middleware/` holds shared request authentication middleware; `src/types/hono.ts` defines typed context variables.
- Files and folders use kebab-case; functions, variables, and Zod schemas use camelCase; types and classes use PascalCase; PostgreSQL tables and columns use snake_case. Keep the current API JSON contract aligned with its consumers when changing response fields.

- Package catalog controllers include `/v1/packages`, `/v1/admin/packages`, and package-image routes. Admins upload JPEG or PNG files (up to 5 MiB); public image access requires a current published version of a nonarchived package. The package and image services preserve row locks during edits and cleanup.
- Service catalog controllers include `/v1/services`, `/v1/services/{id}/packages`, `/v1/admin/services`, and service-image routes. Public package and service lists accept optional `limit` (1–15) and `offset`, returning `nextOffset`; no `limit` retains the full list. The related-packages route returns current published packages with an included assignment to the visible service, including an older service version. Service versions carry category tags and an optional HTTPS or uploaded image. Package versions may hold UUID-identified included service or priced add-on assignments. Public reads expose only current published, nonarchived service offers.
- Messaging controllers cover customer `/v1/messages/conversation` and staff `/v1/admin/conversations` paths. Each customer has one conversation; messages have `read_at`, and customer routes never accept another customer's conversation id.
- Booking request controllers cover customer `POST /v1/booking-requests`, `GET /v1/booking-requests/mine`, and owner-only cancellation, plus staff-readable list and System Administrator status updates under `/v1/admin/booking-requests`. Requests retain the selected published package version and an audit history. An accepted request is only accepted for processing; it is not a confirmed booking or date hold.
- Validate incoming bodies through route schemas and read them with `c.req.valid("json")`. Keep OpenAPI responses consistent with actual handler status codes and bodies. `src/app.ts` applies an allowed-origin check to browser writes and a 16 KiB limit to `/v1/auth/*`.

For a new operation, use the matching domain folder in each layer. For example, `controllers/packages/create-package.ts` exports `createPackageRoute` and `createPackageRouteHandler`, `services/packages/create-package.ts` exports `createPackageService`, and `data/packages/create-package.ts` exports `createPackageData`. Register the route and handler in `controllers/packages/index.ts`. The flow is controller → service → data when business rules are involved; a simple controller can call data directly, and an operation with no database work need not have a data file. Keep existing JSON request and response field names unless the task explicitly changes the API contract and its consumers.

Check the affected route's OpenAPI output and behavior, especially if changing paths or response shapes consumed by `apps/web/src/lib/api.ts`.

- System Administrator access requires role `admin` and staff title `System Administrator`; role `staff` can read booking requests and published catalog, but cannot access administrative catalog, messages, directory, or writes.
- Venue catalog routes provide public active venue list and detail reads, and System Administrator writes. Selecting a venue copies text into a package; it does not create a reservation or check availability.
