# Experience first

Follow the [Clemora workflow adapters](../../shared/skill-adapters.md) and [operating contract](../../shared/agent-workflow.md).

Choose a complete usable journey over implementation convenience or unnecessary controls. Justify each feature and option against the requested outcome. Give loading, empty, invalid, failed, and successful actions clear feedback.

For Clemora, use the current design and shared components, and preserve the distinction between customer, staff, and System Administrator capabilities. An inquiry must not imply a date reservation or final quotation. API callers and maintainers are consumers too: prefer small clear contracts that hide implementation decisions.

Prototype uncertain interactions and inspect the rendered result. Reduce scope only with the user's agreement when it would remove a requested deliverable.
