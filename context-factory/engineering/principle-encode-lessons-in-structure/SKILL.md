# Encode lessons in structure

Follow the [Clemora workflow adapters](../../shared/skill-adapters.md) and [operating contract](../../shared/agent-workflow.md).

When the same correction recurs, prefer one canonical owner, a type constraint, an actionable lint/check, or a behavior test over another copy of the instruction. Prove that the mechanism rejects a representative real mistake and accepts the valid case.

Use prose for decisions requiring judgment, and include a concrete failure example. Remove superseded instructions when structural enforcement replaces them. Follow [correct](../correct/SKILL.md) and keep the change within the authorized task. Record lasting project knowledge under the role memory policy; do not write personal/global memory without user authorization.
