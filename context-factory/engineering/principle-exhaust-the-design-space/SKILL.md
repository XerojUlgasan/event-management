# Exhaust the design space

Follow the [Clemora workflow adapters](../../shared/skill-adapters.md) and [operating contract](../../shared/agent-workflow.md).

When the codebase has no suitable precedent, compare two or three structurally distinct designs or small prototypes before committing to one. State the actual decision criteria and use the same caller journey or constraints for each candidate.

Use [architect](../architect/SKILL.md) for module design. For a novel UI interaction, compare rendered behavior, feedback, keyboard use, and mobile layout. Prototype in scratch space before adding production abstractions. Routine changes with a clear existing pattern do not need competing implementations. Do not expand approved product scope or delegate unless authorized by applicable instructions.
