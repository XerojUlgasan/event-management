# Guard the context window

Follow the [Clemora workflow adapters](../../shared/skill-adapters.md) and [operating contract](../../shared/agent-workflow.md).

Inventory with rg, read bounded relevant regions, cap large outputs, and avoid rereading the same files without a new reason. Keep a concise map of findings, evidence, decisions, gaps, and next actions.

For multi-session work, prefer an existing sanitized repo task note or owning role reference over a long chat-only record. Keep product scope in the README rather than a duplicate overview. Do not replace the full objective with a smaller task to fit context.

Use bounded helpers only when delegation is explicitly authorized by the user or applicable guidance. Otherwise investigate in sequential slices. Tool truncation and context summaries are not proof that omitted material was inspected.
