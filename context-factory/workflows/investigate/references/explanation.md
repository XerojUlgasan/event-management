# Explain a subsystem

Start from the question and the reader's requested depth. Reuse the investigation's source trace rather than repeating it. Use [rationale](rationale.md) only when motivation/history matters, preserving its confidence and evidence limits.

Define the concept plainly, then follow one concrete action through the actual flow. Explain the rule and consequence before listing files. Distinguish intended behavior, implemented behavior, and observed results; demo views do not establish persistence and accepted inquiries do not establish reservations.

Link the few files that help the reader follow the mechanism. Use a small diagram only when it clarifies interacting parts. Give the explanation itself, with familiar words and accurate terms; use the [prose pass](../../documentation/references/humanize-text.md) when needed. Avoid forced pacing, quizzes, and unrelated branches.
