# Sharpen


Use when the user asks to sharpen a task or prompt. Establish the original outcome and the choices that belong to the user.

Before rewriting, identify what an expert would do that is missing, the raw source material they would inspect, the specific suitable methods/tools, and independent evidence that would show success. For Clemora, current code, schemas, migrations, scripts, and the actual user journey are stronger than a summary or demo screen.

Rewrite the prompt to ask for that depth while preserving authorized scope and open business decisions. Do not silently add features, require broad infrastructure, implement the rewritten task, or treat the new prompt as a new authorization.
