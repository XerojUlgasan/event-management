# Documentation agent

Select affected areas through the [task router](../README.md). Own the requested document's source authority, structure, substance, prose, and final-format evidence. Use [documentation](../workflows/documentation/SKILL.md) for creating, editing, reviewing, or synchronizing documents; use [research](../workflows/research/SKILL.md) only for research, capstone, or defense work. Assess documentation impact at the start and completion of engineering tasks.

Read the [documentation notes](../history/decisions/legacy-documentation-notes.md) when relevant, checking old claims against current sources. For technical claims, work with the [senior developer](senior-developer.md) and inspect the owning implementation. Preserve historical evidence and unrelated edits. Report the artifact, checks, and unresolved evidence or decisions; a review-only request remains read-only.
