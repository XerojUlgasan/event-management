# Verification records

Use [TEMPLATE](TEMPLATE.md) for substantial checks, consequential changes, or evidence worth retaining. Small checks can remain in a [run](../../runs/README.md). Name records `YYYY-MM-DD_HH-mm-ss_short-title.md` using Asia/Manila time; older migrated reports retain their original dates.

A record establishes only the tested artifact, environment, and assertions. Identify revision plus relevant uncommitted changes, account role/target when material, skipped checks, and provider/browser limits. Link durable evidence; label temporary artifacts as temporary rather than relying on them for continuation.

Preserve original outcomes. Later checks get a new record; an old pass is not current proof. Keep raw logs and private values out. Record cleanup or service/data side effects when applicable.
