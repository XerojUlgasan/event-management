# Molecules

Reusable combinations of atoms, including panels, stat cards, search fields, tabs, form fields, activity lists, and toasts. `InputGroup` wraps controls with optional leading and trailing content and reflects invalid/disabled plain-control states. `SearchField` supports a native input type. `Tabs` offers underline and segmented filter groups; true tablists require item IDs and panel IDs with matching app-owned panels. Application code owns selection and action handlers. `Toast` supports success/status and danger/alert feedback; the caller owns its lifetime.
