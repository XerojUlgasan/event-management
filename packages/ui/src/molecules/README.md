# Molecules

Reusable combinations of atoms, including panels, stat cards, search fields, tabs, page navigation, form fields, activity lists, and toasts. `InputGroup` wraps controls with optional leading and trailing content and reflects invalid/disabled plain-control states. `SearchField` supports a native input type. `Tabs` offers underline and segmented filter groups; true tablists require item IDs and panel IDs with matching app-owned panels. `Pagination` renders controlled Previous/Next navigation through callbacks or supplied links; the caller owns the page number, cursor, data request, and loading state. `DataTable` remains a separate row-rendering component. Application code owns selection and action handlers. `Toast` supports success/status and danger/alert feedback; the caller owns its lifetime.
